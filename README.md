# Phishing Website Detection (Machine Learning)

A beginner-friendly, GitHub-ready ML project that classifies URLs as **phishing** or **legitimate** using URL lexical features. It includes data generation, model training and comparison, a Streamlit interface, CLI prediction, and evaluation outputs.

> **Educational disclaimer:** This is a demonstration trained on synthetic example data. It is not a security product and should not be relied on to protect users. A URL's lexical features alone cannot establish whether a site is malicious.

## Project topic
From the uploaded *50 Real-World Machine Learning Projects* document, this is **Topic 10: Phishing Website Detection** (Classification Projects, page 2). The brief is to identify suspicious websites using URL characteristics, domain information and webpage features. Suggested algorithms include Logistic Regression, SVM, Decision Tree and Naive Bayes.

## Features
- Extracts URL-only features (length, IP-address host, HTTPS scheme, suspicious tokens, subdomain count, etc.)
- Compares Logistic Regression, Random Forest and Decision Tree
- Train/test split and metrics (accuracy, precision, recall, F1, ROC-AUC)
- Saves a model pipeline and metrics report
- Streamlit web app and command-line prediction
- Synthetic starter dataset; no external dataset download required

## Quick start (Python 3.10+ recommended)
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
python src/generate_dataset.py
python src/train_model.py
streamlit run app.py
```

## Predict via command line
```bash
python src/predict.py "https://example.com"
```

## Dataset
`data/urls.csv` is generated by `src/generate_dataset.py` and contains synthetic URL examples and labels:
- `url`: the URL text
- `label`: 0 = legitimate-like example, 1 = phishing-like example

The generator deliberately creates patterns for learning/demo purposes. For a real project, replace it with a properly licensed, documented dataset and re-run training. Avoid visiting suspicious URLs.

## Workflow
1. Generate/load data
2. Extract URL features
3. Split data using stratification
4. Train and compare baseline models
5. Evaluate on held-out test data
6. Save the best pipeline
7. Use the app/CLI for a demonstration
